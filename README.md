# Hand Gesture Dataset

A video dataset for vehicle control and interactive systems based on hand gesture recognition.

## Gesture Classes

| Gesture / Class | Description | Sample Count |
| :--- | :--- | :--- |
| **`double swipe(wiper)`** | Wiper control gesture | 63 videos |
| **`fist-open plam(engine on-off)`** | Engine start/stop gesture | 120 videos |
| **`left indicator`** | Left turn indicator gesture | 87 videos |
| **`negative`** | Background / non-gesture actions | 28 videos |
| **`palm hold (reset-cancel)`** | Reset / cancellation hold gesture | 100 videos |
| **`right indicator`** | Right turn indicator gesture | 83 videos |
| **`single swipe down(low beam )`** | Low beam headlight switch | 83 videos |
| **`single swipe up(high beam)`** | High beam headlight switch | 80 videos |

**Total:** 644 `.mp4` video clips (~2.48 GB).
